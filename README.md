# Sanil's - Hindi Transliteration Tool
Check out the live link [Hindi Transliteration Tool](https://psanilp.github.io/hindi/)

A lightweight, web-based tool designed to seamlessly transliterate English text into Hindi. 

This project was built to provide a clean, user-friendly alternative to similar transliteration sites found on the internet. It is a completely **ad-free version** that prioritizes user experience—it is perfectly safe to use and will never bug you with intrusive banners, pop-ups, or hidden advertisements.

## ✨ Features
* **Ad-Free & Safe:** A distraction-free interface with absolutely no banners or popups.
* **Real-Time Conversion:** Instantly transliterates your English input (e.g., typing "maine chutiya banaya aapko") into Malayalam characters as soon as you hit space or enter.
* **Original Text Tracking:** Automatically keeps a running log of the original English words you typed at the bottom of the screen.
* **One-Click Actions:** Includes a convenient "📋" button to instantly copy your transliterated text to the clipboard, and a "❌" button to quickly clear the workspace.
* **Responsive Design:** Built with Bootstrap 5.0.2 to ensure the tool looks great and functions perfectly on both desktop and mobile devices.

## 🚀 Acknowledgments & How It Works

**Powered by Google:** The core transliteration engine of this tool operates by securely calling the Google Input Tools API (`https://www.google.com/inputtools/request`). 

When you type a word and press space, the script sends the English word to Google's servers, retrieves the most accurate Malayalam transliteration, and replaces the text in your text box instantly. 

## 🛠️ Usage

Simply open the `index.html` file in any modern web browser. Type your Malayalam words using English letters, hit the spacebar, and watch the text convert!
